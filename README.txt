SDG Record V1.5（V1.4データ互換版）

主な変更
・最大乾燥密度 1803 kg/m³、最適含水比 12.4% を入力画面へ常時表示
・乾燥密度から締固め度（乾燥密度÷1803×100）を自動計算し、小数1桁で一覧表示
・CSVの既存4列を維持し、末尾へ「締固め度(%)」列を追加
・表示中の範囲（今日／全件）を、左測点・右測点に分けて折れ線グラフ表示
・各グラフに平均値、最低値、最高値、93%線、100%線を表示

互換性と保存について
・V1.4と同じ localStorage キー「sdgRecords」を継続使用します。
・測点記憶も同じキー「sdgLastPoint」を継続使用します。
・既存レコードのJSONキーと構造は変更しません。
・締固め度は保存せず、乾燥密度から表示時・CSV作成時に計算します。
・そのため、V1.4の過去データも変更せず、そのまま一覧・グラフ・CSVで利用できます。
・IndexedDBはV1.4で使用されていないため、新設・変更していません。
・CSVは既存列の名称と順序を変えず、5列目だけを追加しています。

動作確認方法
1. 更新前にV1.4からCSVを共有し、念のため別の場所へ保管します。
2. GitHub上の5ファイル（index.html / style.css / app.js / manifest.json / service-worker.js）を差し替えます。
3. アプリを開き直し、過去の記録件数・日付・測点・左右・乾燥密度が更新前と同じか確認します。
4. 過去記録に締固め度が表示されることを確認します。
5. 乾燥密度1745.4を試験登録し、96.8%と表示されることを確認します。
6. 乾燥密度1831.8を試験登録し、101.6%と表示されることを確認します。
7. 「グラフ」を押し、左・右が別々に表示され、93%線・100%線と統計値があることを確認します。
8. CSVを共有し、既存4列が同じ順序で、末尾に締固め度(%)が追加されていることを確認します。

重要
・GitHub上のファイル差し替えでは、同じURL（同じ配信元）で利用する限り端末内データは残ります。
・公開URLやGitHub Pagesのリポジトリ／パスを変えると、ブラウザ上では別の保存領域になります。
・Safariの「履歴とWebサイトデータを消去」、ホーム画面アプリのサイトデータ削除、端末初期化ではデータが消える可能性があります。
・更新前のCSV保管を強く推奨します。
